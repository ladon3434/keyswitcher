# Contributing

Thanks for your interest in KeySwitcher.

- **Bugs and ideas**: open an [issue](https://github.com/ladon3434/keyswitcher/issues). For a bug, include your Windows build, installed input languages and the steps to reproduce.
- **Pull requests**: keep them small and focused. The project stays tiny on purpose: plain WinAPI, no C runtime, no third-party dependencies.
- **Before submitting**: run `build.cmd`; the build treats warnings as errors.
- **Style**: follow `.editorconfig` and the existing code.
