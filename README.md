A tiny Windows 11 tray utility that switches the keyboard layout with a single tap of Ctrl. About 17 KB, plain WinAPI, no C runtime, no dependencies.

## Modes

Click the tray icon (the Armenian letter Ա) to choose a mode:

- **Left Ctrl — next language**: Left Ctrl cycles through the installed input languages.
- **Left Ctrl — primary language, Right Ctrl — secondary**: Left Ctrl selects the first language in your Windows language list, Right Ctrl the second one. Change the order in Settings → Time & language → Language & region.

The menu also has **Start with Windows**, which adds KeySwitcher to your user's startup programs or removes it.

Only a lone, short Ctrl tap (under 0.5 s, no other key or mouse button in between) switches the layout, so Ctrl+C, Ctrl+click, Ctrl+wheel and AltGr keep working. The chosen mode is stored in `HKCU\Software\KeySwitcher\Mode`.

## Languages

The menu follows the Windows display language: English, Russian, Ukrainian, German, French, Spanish, Italian, Portuguese, Polish, Turkish, Japanese, Korean, Chinese (Simplified and Traditional). Other languages fall back to English.

## Install

Download `keyswitcher.exe` from [Releases](https://github.com/ladon3434/keyswitcher/releases) and run it.

To start it with Windows, tick **Start with Windows** in the tray menu.

## Build

Requires Visual Studio 2022 or newer with the **Desktop development with C++** workload.

```
build.cmd
```

The result is `build\keyswitcher.exe`. The icon `res\keyswitcher.ico` is generated by `tools\make-icon.ps1`.

## Limitations

Windows does not deliver keystrokes from elevated (administrator) windows to a non-elevated program. To switch layouts in such windows too, run KeySwitcher elevated, for example via Task Scheduler with «Run with highest privileges».
