# KeySwitcher

[English](README.md)

Крошечная утилита для Windows 11: переключает раскладку клавиатуры коротким нажатием Ctrl. Живёт в трее, весит около 9 КБ, написана на чистом WinAPI без C runtime и зависимостей.

## Режимы

Меню по клику на иконку «Ая» в трее:

- **Левый Ctrl — переключить язык**: левый Ctrl по кругу перебирает установленные языки ввода.
- **Левый Ctrl — русский, правый Ctrl — английский**: каждый Ctrl включает свой язык.

Срабатывает только одиночное короткое нажатие Ctrl (до 0,5 с), без других клавиш и кнопок мыши. Ctrl+C, Ctrl+клик, Ctrl+колесо и AltGr работают как обычно. Выбранный режим хранится в `HKCU\Software\KeySwitcher\Mode`.

## Установка

Скачайте `keyswitcher.exe` со страницы [Releases](https://github.com/ladon3434/keyswitcher/releases) и запустите.

Для автозапуска нажмите Win+R, введите `shell:startup` и положите в открывшуюся папку ярлык на `keyswitcher.exe`.

## Сборка

Нужна Visual Studio 2022 или новее с компонентом «Разработка классических приложений на C++».

```
build.cmd
```

Результат: `build\keyswitcher.exe`.

## Ограничения

Окна, запущенные от администратора, не передают нажатия обычной программе: так устроена защита Windows. Чтобы утилита работала и в них, запускайте её от имени администратора, например через Планировщик заданий с параметром «Выполнить с наивысшими правами».
