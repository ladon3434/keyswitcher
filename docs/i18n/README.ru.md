Крошечная утилита для Windows 11: переключает раскладку клавиатуры коротким нажатием Ctrl. Живёт в трее, весит около 17 КБ, написана на чистом WinAPI без C runtime и зависимостей.

## Режимы

Меню по клику на иконку в трее (армянская буква Ա):

- **Левый Ctrl — следующий язык**: левый Ctrl по кругу перебирает установленные языки ввода.
- **Левый Ctrl — основной язык, правый Ctrl — дополнительный**: левый Ctrl включает первый язык из списка языков Windows, правый — второй. Порядок меняется в «Параметры → Время и язык → Язык и регион».

В меню также есть галочка **«Запускать вместе с Windows»**: она добавляет утилиту в автозагрузку пользователя или убирает её оттуда.

Срабатывает только одиночное короткое нажатие Ctrl (до 0,5 с), без других клавиш и кнопок мыши. Ctrl+C, Ctrl+клик, Ctrl+колесо и AltGr работают как обычно. Выбранный режим хранится в `HKCU\Software\KeySwitcher\Mode`.

## Языки

Меню показывается на языке интерфейса Windows: английский, русский, украинский, немецкий, французский, испанский, итальянский, португальский, польский, турецкий, японский, корейский, китайский (упрощённый и традиционный). Для остальных языков — английский.

## Установка

Скачайте `keyswitcher.exe` со страницы [Releases](https://github.com/ladon3434/keyswitcher/releases) и запустите.

Для автозапуска поставьте галочку «Запускать вместе с Windows» в меню в трее.

## Сборка

Нужна Visual Studio 2022 или новее с компонентом «Разработка классических приложений на C++».

```
build.cmd
```

Результат: `build\keyswitcher.exe`. Иконка `res\keyswitcher.ico` генерируется скриптом `tools\make-icon.ps1`.

## Ограничения

Окна, запущенные от администратора, не передают нажатия обычной программе: так устроена защита Windows. Чтобы утилита работала и в них, запускайте её от имени администратора, например через Планировщик заданий с параметром «Выполнить с наивысшими правами».
