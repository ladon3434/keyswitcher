Крихітна утиліта для Windows 11: перемикає розкладку клавіатури коротким натисканням Ctrl. Живе в треї, важить близько 17 КБ, написана на чистому WinAPI без C runtime і залежностей.

## Режими

Меню за кліком на значок у треї (вірменська літера Ա):

- **Лівий Ctrl — наступна мова**: лівий Ctrl по колу перебирає встановлені мови введення.
- **Лівий Ctrl — основна мова, правий Ctrl — додаткова**: лівий Ctrl вмикає першу мову зі списку мов Windows, правий — другу. Порядок змінюється в «Параметри → Час і мова → Мова та регіон».

У меню також є прапорець **«Запускати разом із Windows»**: він додає утиліту до автозавантаження користувача або прибирає її звідти.

Спрацьовує лише одиночне коротке натискання Ctrl (до 0,5 с), без інших клавіш і кнопок миші. Ctrl+C, Ctrl+клік, Ctrl+коліщатко та AltGr працюють як завжди. Вибраний режим зберігається в `HKCU\Software\KeySwitcher\Mode`.

## Мови

Меню показується мовою інтерфейсу Windows: англійська, російська, українська, німецька, французька, іспанська, італійська, португальська, польська, турецька, японська, корейська, китайська (спрощена й традиційна). Для інших мов — англійська.

## Встановлення

Завантажте `keyswitcher.exe` зі сторінки [Releases](https://github.com/ladon3434/keyswitcher/releases) і запустіть.

Для автозапуску поставте прапорець «Запускати разом із Windows» у меню в треї.

## Збирання

Потрібна Visual Studio 2022 або новіша з робочим навантаженням «Розробка класичних застосунків на C++».

```
build.cmd
```

Результат: `build\keyswitcher.exe`. Значок `res\keyswitcher.ico` генерується скриптом `tools\make-icon.ps1`.

## Обмеження

Вікна, запущені від імені адміністратора, не передають натискання звичайній програмі: так влаштований захист Windows. Щоб утиліта працювала і в них, запускайте її від імені адміністратора, наприклад через Планувальник завдань з параметром «Виконувати з найвищими правами».
